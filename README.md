# Recipe Discovery & Search System

A Phase 1 React application for discovering and searching recipes dynamically using TheMealDB API.

## Features

- React + Vite
- Reusable React components
- Recipe search
- Dynamic API data using Fetch API
- Recipe detail modal
- Category and cuisine information
- Ingredients list
- Loading and error states
- Responsive mobile-friendly UI
- Clean modern interface
Detailed Recipe Pages
Nutrition Information
Advanced Filtering
Favorites Feature
Performance Optimization

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## API

This project uses TheMealDB public development API.

- Search: `https://www.themealdb.com/api/json/v1/1/search.php?s=`
- Details: `https://www.themealdb.com/api/json/v1/1/lookup.php?i=`

This project demonstrates reusable React components, API calls with Fetch, state management, responsive UI, and dynamic recipe results.
